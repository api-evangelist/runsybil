# RunSybil

> RunSybil is an AI-native autonomous offensive security platform. Sybil — a system of AI agents — continuously penetration tests live applications and infrastructure, finding, exploiting, and validating real vulnerabilities without humans in the loop. Founded in 2023 by Ari Herbert-Voss (OpenAI's first security hire) and Vlad Ionescu (Offensive Security Tech Lead, Meta), RunSybil has raised $40M led by Khosla Ventures. Trusted by security teams at Notion, Cursor, Turbopuffer, Baseten, and Thinking Machines Lab.

RunSybil replaces point-in-time penetration testing, legacy DAST/SAST scanners, and bug bounty programs. Sybil tests live applications black-box by default — no source code required — integrates with GitHub and GitLab to trigger targeted change testing on every code push, and validates every finding through a multi-agent pipeline before it surfaces. No triage. No false positives. RunSybil also offers white-box testing for more in-depth exploration of a company's codebase.

Sybil is not a scanner, an EDR solution, an auto-SOC, a code scanner, or an LLM wrapper on a legacy vulnerability tool.
